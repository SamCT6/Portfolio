# Sam Collier-Tenison — Graphic Design Portfolio

This folder contains a complete responsive portfolio website concept.

## Files
- `index.html` — the full website
- `assets/` — portfolio images

## Before publishing
1. Replace `your.email@example.com` with your actual professional email.
2. Review project descriptions and update any details you want to be more specific.
3. If you want to add your resume, add a PDF and a Resume link to the navigation.
4. Upload the folder to a hosting service such as GitHub Pages, Netlify, Vercel, or another static host.

The site is intentionally simple, editorial, and image-forward so the portfolio work remains the focus.
